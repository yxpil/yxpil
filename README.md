## 代表作 Featured Work

### [BIT](https://github.com/yxpil/bit) — 本地优先 AI Agent 中枢

一个可以自我成长的桌面端 AI Agent：工具注册表、MCP 客户端/服务端、可编程技能、远程访问 API，单二进制分发，全平台原生安装包。

- 官网与下载：[osbt.space](https://osbt.space)
- 支持 macOS（aarch64 / x64）、Windows（x64 / ARM64）、Linux（x86_64 / aarch64 / LoongArch64 / RISC-V）
- 自托管软件源：APT / pacman / dnf / Scoop / Homebrew / winget / npm
